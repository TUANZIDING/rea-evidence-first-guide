## 能分析什么 · What you can inspect

| 目标类型 | 能得到什么 | 依赖 |
| --- | --- | --- |
| JavaScript / Electron | 模块、导入、路由、IPC、前后端通信 | Node.js + npm |
| 原生二进制（Windows / macOS / Linux） | 伪代码、汇编、字符串、符号、调用关系 | Hopper / Ghidra / IDA |
| .NET 程序集 | 元数据、CIL指令 | 无（纯静态） |
| 网站 | 页面结构、脚本、网络请求 | Chrome系浏览器 |
| Android APK | Manifest、类、反编译方法 | JADX + 完整JDK |
| 固件 / WASM | 视格式与工具而定 | Binwalk / Unblob / WABT 等 |

完整列表见 [REA官方README](https://github.com/morluto/rea#what-you-can-analyze)（2026-10-23核对）。

| 工具 | 作用 |
| --- | --- |
| REA | 跨分析类型的统一工作流 |
| Ghidra | 重量级反汇编器（NSA开源） |
| GhidraMCP | 代理与Ghidra之间的桥 |
| Frida | 运行时动态观察 |
| radare2 | 命令行二进制分析 |
| JADX | Android反编译 |

## 公开案例 · Case studies

| 案例 | 做了什么 | 结果 | 证据等级 |
| --- | --- | --- | --- |
| DX-Ball（1996） | 从声音调用追到"位置→声道平移"函数 | 通过3,205个原始x86测试用例，复现全部63字节编译代码 | 官方案例；只是一个函数，不是整个游戏 |
| 东方TH04（PC-98，16位DOS） | 恢复弹幕环的固定与瞄准角度计算 | C++重建并与历史编译器输出对比 | 官方案例 |
| Notion剪贴板 | 渲染进程 → preload → IPC → 主进程 | 完整理解一个功能的架构 | 官方案例；研究架构而非代码的范例 |
| stress.exe（2000年免费软件） | Reddit用户用REA加大模型约30分钟重建 | 2小时内发布macOS版和网页版 | 个人构建日志，非独立基准 |

官方案例页：[rea.tools/showcase](https://rea.tools/showcase/)

## 误解与边界 · Myths and boundaries

| 流传说法 | 实际情况 |
| --- | --- |
| "能克隆任何软件" | 不能。不恢复原始源码，不自动克隆；服务端逻辑、加密、外部依赖在本地看不到 |
| "一个提示词取代逆向工程师" | 不能。它加速导航、形成假设和写重建代码，正确性仍要测试证明 |
| "开源所以复制合法" | MIT只覆盖REA本身，不覆盖你分析的软件；版权、许可、服务条款照样适用 |
| "这是全新技术" | Ghidra、radare2、Frida早已存在；新的是这套工作流人人可用 |

**净室实现（clean-room）：** 理解行为 → 写规格 → 只依据规格实现 → 测试，不复制任何原代码。提示词里"不要复制专有源码或素材 / 超出批准范围就停止"两句不是装饰。

用于学习、互操作性、安全研究、软件保存、分析你拥有或获授权的软件，属正常实践；复制他人受保护的代码或素材，任何工具都改变不了其性质。
